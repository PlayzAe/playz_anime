### Shipped Apps & Projects

* **[Quilore](https://quilore.com/) (Live Web App):** 
  Analyzes entire Spotify listening histories directly from raw GDPR export zips in the browser. Spotify's web API drops track durations and only keeps 50 plays, so I reverse-engineered playback timestamp deltas across 160,000+ plays inside Web Workers. Zero server uploads, 100/100 Lighthouse score.
* **[StudyPomo](https://play.google.com/store/apps/details?id=com.everythingabuad.studypomo) (Android):** 
  Pomodoro timer built with persistent foreground services and wake locks specifically tested to survive aggressive OEM task killers on budget phones (like TECNO HiOS).
* **[PlayzAnime](https://playzae.github.io/playz_anime_landingpage/) ([Desktop App](https://github.com/PlayzAe/playz_anime_desktopapp) | [Web Client](https://playz-anime.onrender.com)):** 
  Custom media client with direct CDN-chunked downloads that never die to 0-seeder torrent swarms. Features custom HLS pre-buffering, auto skip intro/outro, and true offline storage.
* **[Ponderanda](https://ponderanda.com/):** 
  Daily five-problem arithmetic progression ladder. Clean, quick, zero paywalls.
* **[Teardowns](https://emberfig.com/teardowns/):** 
  Deep architectural writeups on Spotify timestamp gap analysis and why background timer services keep getting assassinated by modified Android distributions.
